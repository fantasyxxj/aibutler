接入模型 ​

人格要接上 AI 模型才能思考和说话。有两条路：Claude 订阅，或者自己的 API Key。两条可以同时开着，每个人格各选各的。

不会配？

直接问人格：「我有一个 DeepSeek 的 key，怎么接？」它会告诉你每一步点哪里。

两个地方，各管一件事 ​

在哪管什么
系统设置（主窗口右上角「设置」）存「钥匙」：Claude 订阅、API Key。存着不等于在用。
人格管理 → 某个人格 → 「AI」页这个人格用哪把钥匙、哪个引擎、哪个模型。

先在系统设置里存好，再到人格那边选用。

方式一：Claude 订阅 ​

有 Claude Pro 或 Max 订阅，就能让人格用订阅来跑。

  1. 打开系统设置 →「模型服务」→「Claude 订阅」，点「开启」。
  2. 确认后会下载 Anthropic 的 Claude Agent SDK（约 110 MB），下载完点「立即重启」。
  3. 重启后点「登录 Claude」，在浏览器里登录授权。
  4. 看到「已开启并登录」就好了。

然后到人格的「AI」页，「接入方式」选「用订阅账号」。

方式二：API Key ​

存一把 Key ​

打开系统设置 →「模型服务」→「API 凭据」，点「＋ 加一条」，填三项：

项填什么
名字自己认得出就行，比如「DeepSeek」「公司网关」
地址（base_url）服务商给的接口地址，留空默认是 https://api.anthropic.com
Key服务商给的 API Key

填完点「保存」，再点「测试」确认能连上。可以存多条。勾了「默认」的那条，是人格没选凭据、或选的那条被删掉时用的。

让人格用它 ​

到人格管理 → 这个人格 →「AI」页：

  1. 接入方式：选「用系统设置里存的 key」，再选是哪一条。
  2. 引擎：一般选「Butler 引擎（多模型）」。
  3. 模型：从下拉里选；列表里没有的，选「其它 · 手动输入模型名」自己填。

改完要重新打开这个人格才生效。

常见服务商怎么填 ​

服务商地址模型名的写法
Anthropic 官方留空从下拉里选
走 Anthropic 协议的网关网关给的地址照网关给的写
通义千问（大陆）https://dashscope.aliyuncs.com/compatible-mode/v1前面加 compat/，如 compat/qwen-plus
通义千问（国际）https://dashscope-intl.aliyuncs.com/compatible-mode/v1同上
豆包（火山方舟）https://ark.cn-beijing.volces.com/api/v3前面加 compat/，后面写方舟里的模型名
其它 OpenAI 兼容接口服务商给的地址前面加 compat/
OpenAI 官方留空前面加 openai/，如 openai/gpt-5.4-mini

compat/ 的意思是「按 OpenAI 兼容接口去连」，openai/ 是连 OpenAI 官方的新接口。不确定时先用「测试」试，或者问人格。

两种引擎有什么区别 ​

Butler 引擎（多模型）Claude Code
是什么全能管家自带的Anthropic 官方的 Claude Agent SDK
能接的模型Claude、OpenAI、国内大模型、各种网关只有 Claude
什么时候用用 API Key 时的默认选择用 Claude 订阅时自动用它

用订阅的人格固定走 Claude Code；用 Key 的人格两种都能选，「引擎」这一项只有装了 Claude 订阅组件后才会出现。

联网搜索 ​

用 Butler 引擎时，人格默认用模型自带的搜索（有的模型没有）。搜不了或想换，见 联网搜索。

常见问题 ​

人格说「还没选模型，暂时无法回复」 去人格管理 → 这个人格 →「AI」页选一个模型。

报 401 或「key 不对」 系统设置里那条 Key 点「测试」。不通就重新复制粘贴一遍 Key，注意前后不要带空格。

报 400，有时好有时坏 多半是网关或服务商那边临时拒收，等一会儿再发。一直这样，换一条线路试试，或者把报错原文发给人格让它帮你看。

想让几个人格用不同的模型 每个人格的「AI」页各选各的，互不影响。
