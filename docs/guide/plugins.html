插件 ​

不会写没关系。想要什么小工具，跟人格说就行。

插件是带界面的小工具：记账本、待办看板、单词卡、计时器、小游戏……人格会当场给你写好、装上，你点开就能用。

让人格给你做一个 ​

用平常的话说你想要什么，越具体越好：

帮我做一个俄罗斯方块游戏。

做一个记账的小工具：能记每笔花了多少、买了什么，按月看总数。

孩子要练繁体字，做个描红的练习。

它会写好插件、装上、打开给你看。

不满意就接着说：

方块下落再慢一点。

加一个按类别统计的饼图。

做好的插件会一直留着，下次说「打开记账本」就出来。

用现成的插件 ​

问它有什么：

你有哪些插件？

有没有能做番茄钟的？

它会帮你找到并打开。常用的可以让它钉在窗口边上：

把待办看板钉起来。

插件安全吗 ​

  • 插件跑在隔离的沙箱里，碰不到你的文件和系统。
  • 它只能做几类事：显示界面、存自己的数据、把结果交给人格、在你允许的网站上取数据等。
  • 需要密钥的插件，密钥存在本机的保险箱里，插件自己拿不到原文。
  • 从别处来的插件必须通过签名校验才能装。人格给你写的插件在你自己电脑上，不需要签名。

给开发者 ​

插件就是一个 JSON 文件，放进数据目录的 packages.local/ 文件夹就会自动装上，不用重启。格式、可用的功能和例子见 开发者。
