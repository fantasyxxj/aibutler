联网搜索 ​

人格能上网搜资料。用 Butler 引擎的人格，搜索方式在系统设置里定；用 Claude 订阅的人格走 Claude 自己的搜索，不受这里影响。

默认：用模型自带的搜索 ​

什么都不配时，人格用模型服务商自带的搜索。Claude、OpenAI 这类模型一般都有；有的模型或网关没有，那就搜不了。

自己加搜索引擎 ​

系统设置 →「工具」→「联网搜索」：

  1. 点「＋ 添加」，在弹出的列表里选一家：Brave、Tavily 或 SearXNG。
  2. 要 Key 的填 Key，SearXNG 填你自己的服务地址。
  3. 点「测一下」，看到「能用」和第一条结果就对了。
  4. 加了好几家时，用 ↑↓ 排先后，排在上面的先用；一家不通，自动换下一家。
  5. 关掉设置窗口时会问你改动要不要保存，点「保存」。

引擎要 Key中国大陆直连
Brave要（申请）不能，要代理
Tavily要（申请）能
SearXNG填自己的服务地址看你的服务器

在中国大陆推荐加 Tavily，能直连。

加了就只用加的

只要加了引擎，人格就只用这些，不再用模型自带的搜索。想临时换回模型自带的，勾「禁用这些引擎」，加过的配置都留着，取消勾选就恢复。

改完要重新打开人格才生效。
