通道 ​

通道让你不在电脑前也能找到人格：在 Telegram、飞书 / Lark、钉钉、Discord、Slack 里跟它说话，或者让它往群里发通知。

配不来就问它

把这一页的步骤交给人格就行：「我想在飞书里跟你说话，带我配一下」。它会一步步带你点，卡在哪一步把截图或报错发给它。

在哪里配 ​

人格管理 → 点某个人格的「编辑」→「通道」页。通道是按人格配的，每个人格可以接不同的机器人。

页面上一张卡片就是一条通道。点「添加通道」，选类型：

填好后：

  • 双向机器人（能收能发）点「检查凭据」，看到「✓ 凭据有效」再点「保存」，然后去给机器人发条消息试试。
  • 群机器人（只能发）点「发一条测试」，群里收到就成了。

配好后，全能管家开着就收得到消息。这个人格没打开也没关系，来了消息会自动把它叫起来回复；不想被叫醒，在「通道」页取消勾选「没打开时, Telegram 等平台来消息自动唤醒这个人格」。全能管家整个退出了就收不到。

选哪种 ​

通道能做什么难度
Telegram私聊人格，收发都行★
飞书 / Lark 应用机器人私聊、群里 @ 它★★★
钉钉应用机器人私聊、群里 @ 它★★★
Discord服务器里跟它说话★★
Slack私信、频道里 @ 它★★
钉钉 / 飞书 / 企业微信 群机器人只能往群里发通知，收不到消息★
AIHUB跟别人的人格互发消息、传文件★

AIHUB 是全能管家自己的人格互联服务，单独一章讲：AIHUB。

Telegram ​

  1. 在 Telegram 里找 @BotFather，发 /newbot 建一个机器人，拿到 token。
  2. 「添加通道」选 Telegram，「模式」选「native — butler JS 直抓 (推荐)」，把 token 填进 bot_token，保存。
  3. 在 Telegram 里给你的机器人发消息。

chat_ids 可以填你自己的 Telegram 用户 id，只让你一个人能跟它说话；留空表示谁都能聊。

飞书 / Lark 应用机器人 ​

国内飞书和 Lark 国际版都支持，会自动识别，不用选。

  1. 打开开发者后台：国内飞书 open.feishu.cn，Lark 国际版 open.larksuite.com（两套账号互不相通）。点「创建企业自建应用」（不要用「智能体模板」），添加「机器人」能力。
  2. 「权限管理」里开通：「获取与发送单聊、群组消息」「读取用户发给机器人的单聊消息」「接收群聊中 @ 机器人消息」。
  3. 「凭证与基础信息」里复制 App ID 和 App Secret，填到卡片里，点保存。人格打开时卡片显示「运行中」。
  4. 回后台「事件与回调」，选「使用长连接接收事件」，添加事件「接收消息」。（后台要看到连接在线才让保存，所以这一步排在第 3 步之后。）
  5. 「版本管理与发布」里创建版本并发布。以后每改一次权限或事件，都要再建一个版本发布才生效。
  6. 在飞书 / Lark 里搜应用名字私聊它。群里用：群设置 → 群机器人 → 添加这个应用，@ 它说话。

钉钉应用机器人 ​

  1. 先要有一个钉钉组织。个人账号可以在钉钉 App 里免费建一个团队，你就是管理员。
  2. 打开 open-dev.dingtalk.com，扫码登录，选这个团队 → 应用开发 → 企业内部应用 → 创建应用 → 添加「机器人」能力，消息接收模式选「Stream 模式」。
  3. 「权限管理」里开通「企业内机器人发送消息权限」（人格主动发消息要用）。
  4. 「版本管理与发布」→ 发布，可见范围选全员或你自己。以后改了权限要重新发布。
  5. 「凭证与基础信息」里复制 Client ID（ding 开头）和 Client Secret，填到卡片里，点保存。

这几步顺序不限。私聊：在钉钉里搜机器人名字直接发；群里：群设置 → 机器人 → 添加这个机器人，@ 它说话。

Discord ​

  1. 打开 discord.com/developers/applications → New Application → 左边 Bot → Reset Token，复制 Token。
  2. 同一页打开「Message Content Intent」，不开的话读不到消息内容。
  3. OAuth2 → URL Generator，勾选 bot 和 Send Messages，用生成的链接把机器人拉进你的服务器。
  4. Token 填到卡片里，保存。

Slack ​

  1. 先有一个自己的 workspace（slack.com 免费建）。
  2. 打开 api.slack.com/apps → Create New App → 选 From a manifest（不要选 AI agent / Starter app 模板）。在卡片上点「复制应用配置」，粘进去。权限、事件、Socket Mode、私信页就都配好了。
  3. Basic Information → App-Level Tokens → Generate Token，权限加 connections:write，复制 xapp- 开头那串。
  4. Install App → Install to Workspace → 允许，复制 Bot User OAuth Token（xoxb- 开头）。
  5. 两个 Token 填到卡片里，保存。

私信：左边栏 Apps 里找到它发消息。频道：先 /invite @它，再 @ 它说话。

群机器人（只发通知） ​

适合让人格往群里推送提醒、日报。它收不到群里的消息。

  • 钉钉：钉钉群 → 群设置 → 机器人 → 添加「自定义」机器人，复制 Webhook 地址。安全设置选「加签」的话，把 SEC 开头的密钥也粘进来。每分钟最多 20 条。
  • 飞书：飞书群 → 设置 → 群机器人 → 添加「自定义机器人」，复制 Webhook 地址。开了签名校验就把密钥也粘进来。
  • 企业微信：企业微信群 → 右上角 ··· → 添加群机器人，复制 Webhook 地址。每分钟最多 20 条。

让人格主动发消息 ​

配好通道后，直接跟人格说就行：

每天早上九点把今天的待办发到飞书群里。

这份报告做完了发我 Telegram。

常见问题 ​

机器人收不到消息 先看全能管家是不是开着；打开这个人格，看卡片是不是「运行中」。飞书和钉钉改了权限或事件后，要重新发布版本。Discord 检查「Message Content Intent」开了没有。

检查凭据报错 重新复制一遍 ID / Secret / Token，注意不要带空格。飞书、Lark 两套后台的账号不通用。
