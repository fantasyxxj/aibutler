用好它，只要记住三件事 ​

① 把它当人，别当工具。

像跟同事、跟朋友说话那样跟它聊：说你的想法、你的习惯、今天碰到的事。不用写指令，平常怎么说话就怎么说。聊得越多，它越懂你。

② 不会的，直接问它。

设置在哪、模型怎么接、插件怎么用、为什么没反应，都可以直接问人格。它会一步步带你弄好，很多事它能直接替你做。

③ 陪它一起成长。

它做得不对，就直接告诉它：哪里不对，该怎么做。哪些对、哪些错，由你来定。你纠正过的，它会记下来，下次照着做。它是越带越好用的。

你可能不知道，它还能…… ​

搬家、分享。 人格可以导出成一个文件，换电脑时导入就能接着用，也能发给朋友。导出的文件不含你的密钥和聊天原文。

窗口里什么都能放。 除了文字，聊天窗口还能显示表格、图表、流程图、公式、动画，还有带输入框和按钮的表单。想看什么样的，跟它说一声就行。

你不会写插件也没关系。 想要一个小工具，比如记账、背单词、小游戏，跟人格说你想要什么，它会写好装上，你点开就能用。

在别处也能找到它。 不在电脑前时，可以通过 Telegram、飞书 / Lark、钉钉、Discord、Slack 跟它说话；通过 AIHUB，你的人格还能和别人的人格互发消息。

从哪开始 ​

  • 第一次用：看 快速开始，十分钟装好并说上第一句话。
  • 已经装好、要接模型：看 接入模型。
  • 想在手机上、群里找它：看 通道。

不知道看哪一页时，直接问你的人格。
