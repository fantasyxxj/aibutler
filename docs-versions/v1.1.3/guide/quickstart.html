快速开始 ​

从下载到跟人格说上第一句话，大约十分钟。

1. 下载安装包 ​

到 Releases 页面 下载最新版：

你的电脑下载这个
Mac（M1 / M2 / M3 / M4 芯片）aibutler-<版本>-arm64.dmg
Mac（Intel 芯片）aibutler-<版本>-x64.dmg
Windowsaibutler-<版本>-setup.exe

Mac 要 macOS 11 或更高。不知道自己是哪种芯片：点屏幕左上角 →「关于本机」，看「芯片」或「处理器」那一行。

2. 安装 ​

Mac ​

  1. 双击 dmg，把「全能管家」拖进「应用程序」文件夹。
  2. 第一次打开时，系统会提示「这是从互联网下载的 App，确定要打开吗？」，点「打开」。安装包签了名，也通过了苹果的公证，不用做别的设置。

Windows ​

双击 setup.exe 安装。如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

3. 第一次打开：先接上 AI ​

第一次打开会看到两步引导。

第一步「先接上 AI」：人格要接上 AI 模型才能说话，选一种你手上有的：

  • 用 API Key（默认选中）：Anthropic、OpenAI、国内大模型、各种网关的 Key 都行。点「去添加 Key」，系统设置会打开在「模型服务」页：点「＋ 加一条」，先点你用的那家（千问、DeepSeek、Kimi……），地址会自动填好，你只要把 Key 粘进去（详见 接入模型）。
  • 用 Claude 订阅：有 Claude Pro / Max 订阅就选这个。点「开启」，会先下载 Claude 的组件（约 110 MB），下载完重启，再点「登录 Claude」登录一次即可。

右上角可以切换界面语言。弄好后点「下一步」。

第二步「给它起个名字」：这是你的第一个人格，默认叫「管家」，可以改成你喜欢的名字，再挑一个头像。

用 Key 的话，下面会问「要多聪明?」：分「最强 · 很贵」「强」「日常 · 推荐」「省钱」四档，越强越贵。点一档，程序当场在你的 Key 上试出这一档能用的模型，并告诉你用的是哪个。这一档用不了时，它会说明原因（比如没额度、账号没开通这个模型），可以点「换便宜一档」。想自己指定型号，展开「自己选型号」。点「创建并开始」。

「高级」里的两项

「引擎」和「人格资料放在」一般不用动。人格资料的位置建好之后就不能改了，如果你想放到别的盘，建之前在这里点「换个位置」。

4. 说第一句话 ​

人格建好后会先花一两分钟熟悉自己，然后主动跟你打招呼：说它是谁、能帮你做什么，再问你希望它主攻什么方向。直接回答它就行。

想不到要它做什么时，点输入框上方那排按钮（比如「到点提醒我」「帮我查查比比」），点一下就替你发出去。也可以随便说点什么：

你好，我叫小王，平时做设计，以后多帮我盯着点工作上的事。

它会记住你说的，下次接着聊。之后它每天会主动开口一次；你当天第一次找它时，答完正事会顺带提一件快到期或还没做完的事。接下来几件事，都可以直接问它：

  • 「你能帮我做什么？」
  • 「我想在手机上也能找到你，怎么弄？」
  • 「帮我做一个记账的小工具。」

5. 再建更多人格 ​

点窗口上方的「人格 ▾」，选「＋ 新建人格…」。最快的是在顶上的「一句话建人格」里写一句它是做什么的，点「让管家去建」；也可以自己填个名字，用 Key 的话同样可以按「要多聪明?」选一档。点「创建并打开」。每个人格有自己的名字、记忆和模型，互不干扰，比如一个管工作、一个陪孩子学习。

同一个菜单里的「⚙ 管理人格…」打开人格管理：每张人格卡片右上角的「⋯」菜单可以「导出」人格，下方的「从文件导入…」可以把导出的人格装回来。

遇到问题 ​

先问人格。它连不上模型、说不了话时，看 接入模型 里的常见问题。
